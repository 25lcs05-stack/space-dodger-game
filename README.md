# World Clock

A polished, responsive digital clock that displays the current time across multiple time zones.

## Features

- Live local time based on the browser's time zone
- Six preselected world clocks
- Add additional cities from the time-zone picker
- Remove clocks you no longer need
- Toggle between 12-hour and 24-hour formats
- Responsive layout for desktop and mobile
- No dependencies or build step required

## Run locally

Open `index.html` in a browser, or serve the folder with any static web server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.
